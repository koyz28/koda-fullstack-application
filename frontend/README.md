# Frontend – Angular SPA

Angular 22 + Tailwind CSS 4 client for the Client Project Tracker. See the
[root README](../README.md) and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).

```bash
npm install
npm start          # http://localhost:4200, proxies /api to http://127.0.0.1:8000
npm run test:ci    # Vitest unit tests
npm run build      # production build -> dist/frontend/browser
```
